# JICV-replication-package
Replication package for 'Adaptive nonlinear model predictive control for integrated ride comfort and traction control in electric vehicles'

Folder 'MF_Swift' contains the tire models.

Folder 'NMPCs' includes the scripts to build the NMPC s-function used in the 'Performance assessment'section.
Folders 'NMPCs2/3/4' contain the scripts to build the NMPC s-functions used in the 'Real-time implementation analysis' section.
Folder 'Plots' includes the scripts to plot the figures presented in the paper.
Folder 'Results' contains the .mat files of the simulation data.
Folder 'Road_profiles' includes the road profiles used in this study.
Folder 'saved_agent' includes the agents trained in this study.
File 'A1_Init' is used to obtain the results shown in figures 8, 9, 10, 11 and 15.
File 'A2_Full_car_model_parameters_4onBoard' contains the vehicle parameters.
File 'A1_Init' is used to obtain the results shown in figures 8, 9, 10, 11 and 15.
File 'A3_Parameters_MF_Swift' defines the tire models.
File 'A4_KPIs' is used to compute the key performance indicators.
Files 'blockAgentData_front' and 'blockAgentData_rear' are the agents taken from the 'saved_agent' folder.
File 'C1_Full_Car_Model' is the simulink environment associated with file 'C1_MonteCarloAnalysis'.
File 'C1_MonteCarloAnalysis' is used to obtain the results shown in figures 13.
File 'Full_Car_Model' is the simulink environment associated with file 'A1_Init'.
